## A. Red-team composition fixes (encode verbatim)

1. **[CRITICAL] Mixed-version worktrees × migration stamping × merge** — (a) L-37/R-FILE-012: any
   input file with payloads stamped NEWER than the running engine/package set = a named
   **whole-file ours/theirs conflict class** in the merge envelope (parallel to the binary rule),
   never a parse error/undefined; (b) L-26/R-FILE-012: engine/package upgrades are
   **worktree-atomic** — run `context migrate` + commit on a shared base before mixed-version work
   resumes (documented convergence-gate step); (c) annotate L-37 base: tool saves ADVANCE stamps
   (whole-file canonicalize) — "explicit migrate only" is scoped to untouched files; add the
   missing `schema.newer_than_engine` sibling diagnostic for engine kinds.
2. **[MAJOR] Intent-log HMAC logic bug** — R-FILE-004 reword: HMAC key = a **per-project persisted
   secret** (0600 under `.editor/`, same trust class as the attach token), entries additionally
   record the writing incarnationId; state honestly it protects against **corruption +
   cross-project/foreign-log replay, NOT same-user tampering** (tamper safety = the retained
   re-jail + re-CAS on resume). Fixes the impossible "trusts only entries this incarnation wrote".
3. **[MAJOR] Derivation stratification + EditorKernel VM home** — R-FILE-005: derived state =
   f(files, engine version); the registered schema+migration set is a **named derived stratum**:
   pass 0 parses manifests/definition kinds under engine-shipped schemas (keyed WITHOUT the set) →
   produces the registered set; pass 1 parses content keyed WITH the set's derived hash. §3.1:
   EditorKernel hosts the **sandboxed-tier execution environment** (constrained-ABI VM/WASM runtime)
   as a component, booted before pass-1 parsing (cold-start order: lock → index → watcher → VM →
   registration → content parse).
4. **[MAJOR] Live component-schema shape change** — R-LANG-010/R-PLAY-003: a shape/`x-ctx-storage`
   change is **restart-class hot reload** (session discards runtime state, re-instantiates from
   the new derivation; loud event; "preserving state where possible" explicitly excludes it);
   registered layouts carry a **layout hash** checked against each WASM module's declared access
   at load; mismatch = machine-readable load error (R-CLI-008 code).
5. **[MINOR] Migration budget** — L-37 execution contract: per-invocation time/instruction budget +
   cancellation; exhaustion = same diagnostic path as a throwing migration (last-good retained,
   package named).
6. **[MINOR] Unthrottled-loop service point** — R-HEAD-003/R-CLI-006: even unthrottled, the loop
   provides a **bounded per-tick service point** (queries + inter-tick GC window sample at tick
   boundaries; the 5ms p99 measured against it; "unthrottled" = no render waits, not no service
   points).
7. **[MINOR] Composed resource budgets** — new `watcher.degraded` diagnostic/event when watch
   registration fails/truncates (silent crawl-latency fallback is forbidden); N-daemons-on-one-box
   row in the R-FILE-011 bench + R-QA-012 manifest; `context doctor` checks per-user watch/fd
   limits vs project size (R-BUILD-008).
8. **[MINOR] Drift-pair rule** — rewrite plan §5.1 step 3 to cite R-CLI-010 (capability handshake;
   v1 behavior hard-fail); adopt: **requirements are the single normative home** — L-28/L-54/L-58
   lock rows + plan flows become pointer+rationale-delta (retire mirrored full texts);
   R-CLI-015 owns ring-retention wording (R-BRIDGE-008 points at it). Plus one sentence:
   generation-consistent snapshots for slow pagers are bounded via the R-CLI-017 materialize-to-
   handle path (no MVCC).
